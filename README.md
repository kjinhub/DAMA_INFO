# 담아 (DAMA)

> 계획을 세우는 마음이, 하루의 실천으로 이어지도록.

## 담아를 만들게 된 이유

저는 계획을 세우는 것을 좋아합니다. 노션에 일정을 정리하고, 휴대폰 앱에 할 일을 적으며 하루를 잘 보내고 싶었습니다. 하지만 정성껏 세운 계획을 자주 다시 들여다보지는 못했고, 일정 관리도 생각처럼 꾸준히 이어지지 않았습니다.

제 하루를 돌아보니, 계획을 실천하는 과정이 여러 곳에 흩어져 있었습니다. 일정은 노션에서, 할 일은 휴대폰 앱에서, 집중할 때는 네이버 타이머를 켰습니다. 한 가지 일을 하려고 다른 창을 열고, 다시 원래의 계획으로 돌아오는 일이 반복됐습니다. 계획을 적어 둔 공간과 실제로 시간을 보내는 공간이 자꾸 멀어지고 있었습니다.

그래서 **계획을 세우고, 할 일을 확인하고, 집중하고, 오늘을 기록하는 일을 한곳에서 할 수 있으면 좋겠다**고 생각했습니다. 제 삶을 돌아보기 위해 자연스럽게 다시 찾아오는 공간. 담아는 그 필요에서 시작됐습니다.

## 다시 들어오고 싶은, 나만의 다이어리

그 공간에는 제 취향도 담고 싶었습니다. 한국 전통 문양과 한지의 질감을 오늘의 감각으로 풀어내, 차분하면서도 개성 있는 화면을 만들고자 했습니다. 사용자가 테마를 고르고, 스티커를 붙이고, 홈 카드를 배치하며 자신만의 다이어리를 꾸밀 수 있도록 했습니다.

다이어리 꾸미기와 자기 기록을 즐기는 20~30대들이 함께 사용하는 공간을 생각하며 기획했습니다. 각자의 취향에 맞게 꾸민 화면이, 오늘의 계획을 다시 펼쳐 보는 작은 이유가 되었으면 합니다.

## 작은 실천을 함께 쌓는 해태

담아에는 한국 전설 속 동물인 **해태**가 함께합니다. 듀오링고처럼 매일의 작은 활동이 다음 날 다시 찾아올 이유가 되는 경험을 떠올리며, 화면을 돌아다니는 해태에게 사용자가 하루 동안 해낸 일을 함께 담고 싶었습니다.

오늘 등록한 할 일이나 일정 하나를 완료하면 해태가 하루에 한 번 성장합니다. 해태의 레벨은 **내가 세운 계획을 하루에 하나라도 실천한 날이 얼마나 쌓였는지** 보여주는 지표가 됩니다. 앞으로는 이런 날들을 잔디처럼 차곡차곡 채워 보는 활동 기록으로도 이어가고 싶습니다.

오늘 해낸 일 하나가 기록으로 남고, 그 기록이 쌓여 해태도 함께 자라는 경험. 담아가 여러분에게도 **내 하루를 담아 두고, 내일 다시 찾아오고 싶은 공간**이 되었으면 합니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| 나만의 홈 | 달력·일정·할 일·최근 기록 카드를 이동하고 크기를 조절해 배치합니다. |
| 일정과 할 일 | 월간·주간으로 계획을 보고, 시간을 지정한 할 일과 종일 할 일을 함께 관리합니다. |
| 기록하기 | 문서함과 태그로 기록을 정리하고 관련 기록을 연결합니다. |
| 지식 지도 | 기록 사이의 연결을 시각적으로 살펴봅니다. |
| 뽀모도로 | 집중·휴식 시간을 정하고 전통 문양 시계로 시간을 확인합니다. |
| 배경 테마 | 한지·옥빛 한지·연지 한지·유등 밤 등 취향에 맞는 배경을 선택합니다. |
| 해태 | 화면을 함께 다니는 해태를 만나고 활동에 따른 성장을 확인합니다. |
| 서비스 공지 | 로그인한 화면에서 게시 중인 서비스 안내를 확인합니다. |

관리자는 같은 사이트의 `/admin`에서 회원 상태·공지·관리 작업 기록을 관리합니다. 일반 회원과 관리자 권한은 서버에서 구분하며, 관리자 화면에 개인 기록·일정·첨부 내용 열람 기능은 제공하지 않습니다.

## 화면 미리보기

아래 이미지는 **v0.2.0 로컬 미리보기의 실제 웹 화면**입니다. 2026년 10월 17일에 기본 예시 데이터로 촬영했습니다. 실행 환경과 화면 크기에 따라 배치가 달라질 수 있습니다.

### 월간 일정

날짜별 일정과 할 일을 함께 확인합니다. 일정이 많은 주는 행 높이가 늘어나 모든 항목을 보여줍니다. 날짜 범위를 드래그하면 여러 날에 걸친 종일 일정을 등록할 수 있습니다.

![월간 달력에 함께 표시되는 일정과 할 일](assets/screenshots/calendar-month.png)

### 주간 시간표

시간이 있는 일정과 할 일은 해당 시간대에, 시간이 없는 할 일은 종일 영역에 표시합니다. 월간과 주간은 각각의 탐색 위치를 기억합니다.

![종일 영역과 시간대별 일정이 있는 주간 시간표](assets/screenshots/calendar-week.png)

### 기록하기

문서함·태그·즐겨찾기로 기록을 정리하고 관련 기록을 연결합니다.

![문서함과 기록 목록, 선택한 기록 본문을 함께 보는 화면](assets/screenshots/notes.png)

### 지식 지도

연결된 기록을 지도에서 살펴보고 기록 간 관계를 따라갑니다.

지식 지도 이미지는 기본 예시 기록에 소개용 연결 데이터를 더해 촬영했습니다.

![기록과 연결을 시각화한 지식 지도](assets/screenshots/knowledge-map.png)

### 뽀모도로와 유등 밤

집중·휴식 시간과 문양을 오른쪽 패널에서 설정합니다. 문양은 선택 즉시 미리 볼 수 있고, 설정을 저장하면 선택이 확정됩니다. 유등 밤에서도 문양의 원래 색상을 유지합니다.

![유등 밤 배경의 뽀모도로와 오른쪽 문양 설정 패널](assets/screenshots/pomodoro-night.png)
