# 담아 (DAMA)

> 계획을 세우는 마음이, 하루의 실천으로 이어지도록.

## 담아를 만들게 된 이유

저는 계획을 세우는 것을 좋아합니다. 노션에 일정을 정리하고, 휴대폰 앱에 할 일을 적으며 하루를 잘 보내고 싶었습니다. 하지만 정성껏 세운 계획을 자주 다시 들여다보지는 못했고, 일정 관리도 생각처럼 꾸준히 이어지지 않았습니다.

제 하루를 돌아보니, 계획을 실천하는 과정이 여러 곳에 흩어져 있었습니다. 일정은 노션에서, 할 일은 휴대폰 앱에서, 집중할 때는 네이버 타이머를 켰습니다. 한 가지 일을 하려고 다른 창을 열고, 다시 원래의 계획으로 돌아오는 일이 반복됐습니다. 계획을 적어 둔 공간과 실제로 시간을 보내는 공간이 자꾸 멀어지고 있었습니다.

그래서 **계획을 세우고, 할 일을 확인하고, 집중하고, 오늘을 기록하는 일을 한곳에서 할 수 있으면 좋겠다**고 생각했습니다. 제 삶을 돌아보기 위해 자연스럽게 다시 찾아오는 공간. 담아는 그 필요에서 시작됐습니다.

## 다시 들어오고 싶은, 나만의 다이어리

그 공간에는 제 취향도 담고 싶었습니다. 한국 전통 문양과 한지의 질감을 오늘의 감각으로 풀어내, 차분하면서도 개성 있는 화면을 만들고자 했습니다. 사용자가 테마를 고르고, 스티커를 붙이고, 홈 카드를 배치하며 자신만의 다이어리를 꾸밀 수 있도록 했습니다.

다이어리 꾸미기와 자기 기록을 즐기는 20~30대들이 함께 사용하는 공간을 생각하며 기획했습니다. 각자의 취향에 맞게 꾸민 화면이, 오늘의 계획을 다시 펼쳐 보는 작은 이유가 되었으면 합니다.

## 작은 실천을 함께 쌓는 해태

담아에는 한국 전설 속 동물인 **해태**가 함께합니다. 듀오링고처럼 매일의 작은 활동이 다음 날 다시 찾아올 이유가 되는 경험을 떠올리며, 화면을 돌아다니는 해태에게 사용자가 하루 동안 해낸 일을 함께 담고 싶었습니다.

오늘 등록한 할 일을 완료하면 해태가 하루에 한 번 성장합니다. 해태의 레벨은 **내가 세운 계획을 하루에 하나라도 실천한 날이 얼마나 쌓였는지** 보여주는 지표가 됩니다. 통계에서는 출석과 할 일 등록 활동을 잔디처럼 차곡차곡 돌아볼 수 있습니다.

오늘 해낸 일 하나가 기록으로 남고, 그 기록이 쌓여 해태도 함께 자라는 경험. 담아가 여러분에게도 **내 하루를 담아 두고, 내일 다시 찾아오고 싶은 공간**이 되었으면 합니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| 나만의 홈 | 오늘의 계획과 빠른 작성을 확인하고, 달력·일정·할 일·최근 기록 카드를 이동하거나 크기를 조절합니다. 다음 할 일은 상세 확인 뒤 수정·완료를 따로 선택합니다. |
| AI로 계획 정리 | 빈 화면에서 새 요청을 작성하거나 보관한 초안을 골라 이어 씁니다. 일정·할 일 카드를 확인·수정한 뒤 종류별 개수를 보고 확정합니다. |
| 일정과 할 일 | 월간·주간으로 계획을 보고, 휴대폰에서는 오늘의 일정·할 일 목록을 확인합니다. 직접 등록창에서는 저장을 눌러 등록하며 기기 초안은 보관하지 않습니다. AI 등록 초안은 별도로 서버에 이어서 보관합니다. Google 캘린더를 자동으로 연결하고 추가 권한 승인 후 Google Tasks도 가져옵니다. 완료 체크는 할 일에 사용합니다. |
| 기록하기 | 별도 목록과 넓은 편집기에서 기록을 쓰고, 문서함·태그·즐겨찾기와 열린 기록 탭으로 정리합니다. |
| 기록 분석과 질문 취향 | 요일·시간대별 기록 작성 패턴과 일정 등록 수·할 일 완료율을 살펴봅니다. 홈이나 기록 분석에서 하루 세 사색 질문에 답하고, 좋아요·질문 교체·관심 주제와 깊이로 질문 취향을 조절합니다. AI 전송은 기본 허용이며, 직접 꺼 둔 설정은 유지하고 원할 때 끌 수 있습니다. |
| 생각의 탑 | 저장한 기록을 돌블록으로 쌓고 선택한 펫과 함께 높이·다음 쉼터를 확인합니다. 돌에서 기록 원문을 펼치거나 편집 화면으로 이동합니다. |
| 활동 통계와 배지 | 최근 1년·연도별 잔디와 출석·꾸준함·계획·실행·기록의 오각형 비율을 확인하고, 획득한 배지의 진행률·관련 활동을 볼 수 있습니다. |
| 랭킹 | 누적 **Lv. 펫**과 이번 주 기록·계획·실행·응원을 친구 또는 전체 사용자와 비교합니다. 선택한 펫과 색도 볼 수 있습니다. |
| 친구와 알림 | 초대 코드·링크로 친구를 맺고 응원·짧은 답장과 선택한 기록을 나눕니다. 상단 종 아이콘에서 소식을 확인합니다. |
| 뽀모도로 | 집중·휴식 시간을 정하고 전통 문양 시계로 확인하거나 친구와 같은 방에서 함께 집중합니다. |
| 배경 테마 | 한지·옥빛 한지·연지 한지·유등 밤 등 취향에 맞는 배경을 선택합니다. |
| 펫 | 해태·아기 봉황·고양이 소녀 중 함께할 펫을 고르고, 선물받은 고양이 소년·분홍 햄스터·청룡도 선택할 수 있습니다. 활성 관리자는 신규 펫 세 종을 선물 없이 선택할 수 있습니다. 펫 색을 바꾼 뒤 기본 색으로 되돌릴 수 있습니다. 색상과 함께하기 동작을 설정하고 선택한 펫을 친구에게 보낼 수 있습니다. |
| 감정 스티커 | 기쁨·슬픔·분노·우울함 등 32종으로 날짜와 일정·할 일에 감정을 표현합니다. |
| 계정 보호 | 이메일을 인증해 비밀번호 재설정 링크를 받고, 비밀번호 변경·복구 코드를 관리합니다. |
| 앱 설치·업데이트 | 지원 브라우저에서 앱으로 설치하고, 앱 정보에서 버전별 변경 내용을 확인합니다. |
| 서비스 공지 | 알림함에서 관리자 공지와 리뷰 이벤트를 확인합니다. 새 공지는 짧은 상단 알림과 선택한 펫이 알려줍니다. |


관리자는 같은 사이트의 `/admin`에서 회원 관리와 공지·비공개 리뷰 접수·작업 기록을 관리하고, 회원에게 오라나 펫을 선물할 수 있습니다. 서비스 상태에서는 최근 성공한 백업·배포 시각을 확인할 수 있습니다. 일반 회원과 관리자 권한은 서버에서 구분하며, 관리자 화면에 개인 기록·일정·첨부 내용을 열람하는 기능은 제공하지 않습니다.
